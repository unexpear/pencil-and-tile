# Pencil & Tile support Discord

A support and feedback server for Pencil & Tile players and testers, kept completely separate from
the owner's personal accounts.

## 1. A brand-new identity (owner does this)

1. Make a new Google account just for the app (for example a "pencilandtile.support" Gmail). Use it for
   nothing personal.
2. Sign up at discord.com with that email. Pick a username like `pencil-and-tile`, turn on two-factor
   sign-in (User Settings → My Account), and don't link Spotify, Xbox, YouTube or other personal
   connections.
3. Optional: use the same email as the Play listing's support email so all support lives in one inbox.

## 2. Create the server

"+" → Create My Own → For a club or community → name **Pencil & Tile**, icon `docs/store/graphics/icon-512.png`.

Then Server Settings → Enable Community (this adds the rules screen and announcement channels).

### Channels

| Category | Channel | Purpose |
|---|---|---|
| START HERE | #welcome | Read-only. What the app is, how to join testing, where to ask. |
| | #rules | Read-only. The rules below. |
| | #announcements | Read-only. New versions and what's in them. |
| HELP | #help | Questions and problems. One thread per problem (make it a Forum channel with tags: Bug, Question, Solved). |
| | #bug-reports | Forum channel. Template below. |
| FEEDBACK | #ideas | Forum channel for game ideas and suggestions. |
| | #translations | Mistakes or improvements in 中文, 日本語, Español, Deutsch. |
| PLAY | #puzzle-chat | General chat about the games. |
| | #screenshots | Share wins and funny moments. |
| TESTERS | #testers | Closed-testing talk. Visible to the Tester role only. |

No voice channels; they're hard to moderate for a small team.

### Roles

- **Developer**: the owner's support account. Can manage messages.
- **Moderator**: trusted helpers, added later.
- **Tester**: people in the Play closed test. Unlocks #testers.
- Everyone else: the default.

### Safety settings (Server Settings)

- Moderation → Verification level **Medium** (verified email, on Discord 5+ minutes).
- Moderation → Explicit image filter: **filter messages from all members**.
- AutoMod: turn on **Block spam content**, **Block mention spam** (limit 5), and **Block commonly flagged
  words** (all three lists). Add a custom rule that blocks invite links from other servers.
- Safety Setup → turn on DM and friend-request spam protection.
- Privacy: in #help, remind people never to post emails, phone numbers or passwords. Pencil & Tile never
  asks for any account.

Discord's own minimum age is 13, which fits the app's Teen / PEGI 12 rating (Wordsworn has stylised
blood). Keep every channel family-friendly; nothing needs an age-restricted channel.

### #rules

> 1. Be kind. No harassment, hate, slurs or personal attacks.
> 2. Keep it family-friendly. No adult content, gore or shock images.
> 3. Keep your privacy. Don't share emails, phone numbers, addresses or passwords, yours or anyone's.
> 4. No spam, advertising or invite links to other servers.
> 5. Stay on topic in each channel; use threads for long discussions.
> 6. Spoilers: wrap puzzle answers in ||spoiler bars||.
> 7. Moderators' decisions are final. Report problems with Discord's report tool or by pinging @Moderator.

## 4. After it's made

Send the permanent invite link (Server Settings → Invites, never expires, no member limit). It can go on
the app's Settings → About screen, in the Play listing's full description and in `README.md`.
