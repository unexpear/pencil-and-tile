# Pencil & Tile: Google Play store listing

Paste each language's text into Play Console → Grow → Store presence → Main store listing (English is the
default; add the others under "Translations"). Limits: title 30 characters, short description 80, full
description 4,000. `python docs/store/check_listing.py` checks them.

Avoid other companies' game names in store text and keywords (no "Wordle", "Connections", "Boggle",
"Scattergories", "KenKen", "Tetris", "Othello").
